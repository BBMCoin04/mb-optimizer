# Third-party notices

MB CF Optimizer downloads and executes the official
[XIU2/CloudflareSpeedTest](https://github.com/XIU2/CloudflareSpeedTest) Windows
binary as a separate process. CloudflareSpeedTest is licensed under GPL-3.0.

Pinned engine release: `v2.3.5`

The engine is not copied into this source repository. On first use, the app
downloads `cfst_windows_amd64.zip` from the official GitHub release and verifies
its published SHA-256 checksum before extraction. CloudflareSpeedTest source and
license information are available from its upstream repository and release page.
